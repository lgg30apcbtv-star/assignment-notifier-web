# 과제알림 · 공강맞춤

대학생 과제 마감 누락을 줄이기 위한 모바일 우선 웹앱 기초입니다.

## 실행

Node.js 18 이상이 설치되어 있으면 프로젝트 폴더에서 아래 명령으로 실행합니다.

```bash
npm run dev
```

`http://localhost:4173`에서 앱을 열 수 있습니다. 의존성 설치 없이 Node.js 기본 모듈만 사용합니다.

## 현재 포함된 기능

- 과목, 과제 제목, 마감 일시를 빠르게 등록
- 오늘/내일 마감 프리셋과 직접 날짜 선택
- 브라우저 로컬 저장, 마감 임박순 정렬, 오늘/이번 주 필터
- 완료 처리, 완료 취소, 과제 삭제
- D-3, D-1, 3시간 전 브라우저 알림 (알림 권한 허용 및 앱을 열어 둔 상태)
- 알림 일정 미리보기, 과목 목록, JSON 내보내기, 전체 삭제
- 모바일 및 데스크톱 반응형 레이아웃

## 기초 버전의 범위

과제와 설정은 현재 브라우저 `localStorage`에 저장됩니다. 기기 간 동기화, 계정, 서버 데이터베이스, 앱을 닫은 뒤에도 도착하는 푸시 알림은 아직 연결하지 않았습니다. 백그라운드 알림에는 서비스 워커와 푸시 서버 구성이 추가로 필요합니다.
